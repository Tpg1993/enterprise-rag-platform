SECTION 1: OVERVIEW & SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
The Enterprise Multi-Architecture RAG Platform is built to compare, evaluate, 
and observe 10+ retrieval-augmented generation architectures side-by-side. 
It uses Sarvam AI (sarvam-105b) as the primary LLM provider, Qdrant for dense 
vector search, BM25 for sparse lexical retrieval, and Cross-Encoders for reranking.

Key Performance Benchmarks:
- Target Context Precision: 0.95+
- Target Context Recall: 0.92+
- P95 Search Latency: 450ms
- Target Faithfulness (Anti-Hallucination): 0.98+

SECTION 4: KUBERNETES & DEPLOYMENT INSTRUCTIONS
--------------------------------------------------------------------------------
Production clusters are deployed using Infrastructure-as-Code via Terraform 
on AWS Kubernetes (EKS).

Deployment Steps:
1. Initialize Terraform configuration: `terraform init`
2. Apply infrastructure changes: `terraform apply -auto-approve`
3. Update kubeconfig cluster context: `aws eks update-kubeconfig --name rag-prod-cluster`
4. Deploy Core microservices: `helm upgrade --install rag-core ./helm/rag-core`
