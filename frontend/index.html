⚡ RAG Strategies & Multi-Architecture Catalog

Interchangeable production-grade RAG strategies inherited from BaseRAGStrategy abstraction.

1. Basic RAG

Dense vector search using BAAI/bge-m3 embeddings in Qdrant Vector DB, followed by Sarvam-105B LLM generation.

Baseline Dense

2. Hybrid RAG

Concurrent Qdrant dense vector search + BM25 sparse lexical search fused via Reciprocal Rank Fusion (RRF_Score = ∑ 1 / (60 + r_i)).

Dense + Lexical (RRF)

3. MMR RAG

Maximal Marginal Relevance balances query relevance with pairwise candidate diversity (λ=0.7) to eliminate redundant context.

Redundancy Elimination

4. Cross-Encoder Reranked

Fetches Top-50 candidates and applies deep cross-attention re-scoring via local BGE Cross-Encoder to output Top-5 context chunks.

Deep Cross-Attention

5. Parent-Child RAG

Searches small child vector chunks and resolves to full parent paragraph background context for rich grounding.

Context Expansion

6. Multi-Query RAG

Prompts Sarvam-105B to rephrase user prompt into 3 technical query variations, executing parallel vector searches and RRF fusion.

Query Expansion

7. HyDE RAG

Generates hypothetical answer document using Sarvam-105B, embedding hypothetical passage to retrieve dense vector matches.

Hypothetical Embeddings

8. Adaptive RAG

Dynamic query intent classifier classifying complexity (BASIC, HYBRID, MULTI_QUERY, RERANKED) to route to optimal RAG pipelines.

Intent Classification

9. Corrective RAG (CRAG)

Evaluates retrieval confidence score (< 0.5 threshold) and automatically triggers web search fallback when internal knowledge is low.

Web Search Fallback

10. Self-RAG

Self-grading candidate document relevance and computing answer faithfulness scores to execute prompt self-reflection loops.

Self-Reflection Loops

11. ReAct Agentic RAG

Reasoning + Acting Tool Execution Loop in LangGraph iterating through Thought, Tool Action, and Observation cycles.

LangGraph Agent

12. GraphRAG (Neo4j)

Multi-hop knowledge graph traversal in Neo4j coupled with Qdrant dense vector search for relationship-dense queries.

Neo4j Cypher Traversal

13. SQL RAG (PostgreSQL)

Natural language to validated PostgreSQL queries with AST security guardrails, row limits, and read-only execution.

AST Validated Text-to-SQL

14. Multimodal RAG

Joint retrieval over textual chunks, structured tables (Markdown), and visual image figures with modality-aware reranking.

Tables + Vision Figures

15. Hybrid-Graph-Agentic RAG

Unified architecture fusing Dense Qdrant vectors + BM25 Lexical + Neo4j Graph traversal via BGE Reranker into a LangGraph ReAct agent.

Unified Pinnacle Agent
